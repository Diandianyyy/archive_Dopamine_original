# opa334/Dopamine backup

Public backup of https://github.com/opa334/Dopamine.

Downloads: https://github.com/Diandianyyy/archive_Dopamine_original/releases/latest

Checks all releases every six hours, including prereleases and all asset variants. Preserves old releases and replaced assets. Original timestamps and release metadata are attached as _upstream-release.json. Full Git branches/tags/history are recoverable from source bundles in the archive-source-history release.

Packages are checked for size, upstream SHA256 when available, and ZIP integrity for IPA/TIPA. Failures are recorded in the Actions report; other files continue and failures retry next run. This is an unofficial archive, not an APT source.
